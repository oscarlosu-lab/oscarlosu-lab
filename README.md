## Engineering & Trust Standards

- **Cryptographic Verification**: `SHA256SUMS.txt` manifests, SignPath Foundation OSS code signing, and Microsoft WHQL-certified kernel drivers.
- **Automated Security**: Continuous **CodeQL SAST**, **Gitleaks** secret scanning, **Dependabot**, and **OpenSSF Scorecard** checks.
- **Privacy First**: Local-first tools with zero telemetry or mandatory cloud accounts.
